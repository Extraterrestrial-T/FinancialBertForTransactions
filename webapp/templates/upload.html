Upload CSV

Custom input

Score one transaction window

Upload a CSV for one account. The server reads it for this request only, validates the schema, runs the selected adapter, and does not write the file to disk. This is useful for inspecting how the fixed Czech-trained model behaves on aligned data, not for claiming it has been validated on your institution's data.

CSV columns

Required fields describe the event schema used by the model.

ColumnMeaning
trans_dateDate or timestamp of transaction
amountSigned transaction amount
balanceBalance after the transaction
trans_typeC, D or P in the Czech source convention
operationOptional transaction operation
categoryOptional transaction category
other_bank_idOptional bank or counterparty category
account_idOptional. One account per file.
create_dateOptional account opening date. Without it, the first uploaded event is used.

Unknown categories are accepted, but map to the tokenizer's unknown token. If your columns mean something different from these fields, the output is not meaningful.

Optional. Earlier rows are removed.
Optional. Defaults to the final transaction date.

Maximum upload: 10,000 rows and 5 MB. CSV data is not persisted.
